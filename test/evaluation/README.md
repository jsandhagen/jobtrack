Run the semantic counterexamples with `node test/semanticEvidence.test.js` and the broader matrix with `JOBTRACK_EVALUATION_REVISION=<commit> node test/evaluation/techStrategyMatrix.js /tmp/jobtrack-evaluation`.

The matrix uses repository resume fixtures, realistic generated jobs, and explicitly labeled concise paraphrases of public listings. It does not fetch current vacancies. It writes every optimized resume, source text, extraction result, and scoring result for review. Assertions check that optimization preserves source roles, bullet wordings, and the bank; the report also exposes lost requirement coverage for investigation rather than treating score increases as proof of quality.

This is an offline evaluation of extraction, scoring, optimization, and supplied draft validation. It does not measure live Claude generation quality, Electron UI behavior, or real ATS vendor accuracy. The semantic checks deliberately include negation, learning, research, collaborator mentions, employer context, alternative requirements, borrowed metrics, scope escalation, and cross-role provenance.

Run `node test/evaluation/auditMatrix.js /tmp/jobtrack-evaluation` after the matrix to validate source-backed tools, specialty tenure, retained investment requirements, negation, and strategy tailoring. The audit records coverage losses separately so that omissions remain visible even when factual checks pass.
